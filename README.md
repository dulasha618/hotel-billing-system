# Hotel Billing System

A desktop billing and management system for a hotel / cafe, built with C# (Windows Forms) and MySQL.

## Features
- Admin and cashier login
- Manage categories and products
- Create customer orders and print bills
- Cashier management
- Sales and income reports
- System settings

## Built With
- C# (.NET Framework 4.5, Windows Forms)
- MySQL
- Guna.UI2 (UI library)
- Visual Studio

## Getting Started

1. Install [XAMPP](https://www.apachefriends.org/) (or any MySQL server) and start MySQL.
2. Create a database named `cafeshopmanagemantsystem` and import `cafeshopmanagemantsystem.sql` into it.
3. Open `Hotel_Billing_System.csproj` in Visual Studio.
4. If your MySQL settings differ, update the connection string in `App.config`
   (default: `server=localhost; user id=root; database=cafeshopmanagemantsystem`).
5. Build and run the project (F5).
